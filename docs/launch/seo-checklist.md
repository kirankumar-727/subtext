# Launch SEO Checklist

- [x] Canonical article URL model `/{pillar}/{slug}`.
- [x] Metadata title/description overrides and fallbacks.
- [x] Open Graph and X/Twitter metadata.
- [x] Article and BreadcrumbList JSON-LD.
- [x] Semantic headings, byline, dates and source section.
- [x] Search pages are noindex.
- [x] Admin is noindex and disallowed by robots.
- [x] Public robots route declares sitemap and disallows internal APIs.
- [x] Sitemap and RSS query only safe published views.
- [x] Historical editorial paths use HTTP 301.
- [ ] Validate deployed canonical/article metadata against the real article.
- [ ] Validate JSON-LD with a structured-data validator.
- [ ] Submit production sitemap to Google Search Console and Bing Webmaster Tools.
- [ ] Verify draft/unpublished URL absence from indexes and sitemap.
- [ ] Confirm DNS cutover does not retain Shopify canonicals/sitemap.
