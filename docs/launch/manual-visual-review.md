# Manual Mobile, Tablet and Desktop Review

Run only against the deployed application with the real validation article.

## Viewports

- Phone: 375 × 812 and a real narrow mobile device
- Tablet: 768 × 1024
- Desktop: 1440 × 900 or wider

## Review each viewport

- [ ] Header hierarchy and mobile menu are clear and keyboard-operable.
- [ ] Homepage featured story has intentional hierarchy and no layout shift.
- [ ] Four pillar pages preserve their distinct editorial tone without visual gimmicks.
- [ ] Article headline, dek, byline and hero remain balanced.
- [ ] Reading measure is comfortable; no horizontal body/table/code overflow.
- [ ] Cover and inline derivatives select sensible sizes/crops.
- [ ] Alt text, captions and credits are present.
- [ ] Quote, table, footnotes, citations and `:::subtext` are readable.
- [ ] Search field/results are usable by keyboard and touch.
- [ ] About, empty, loading, 404 and error states feel production-ready.
- [ ] Footer is legible and not crowded.
- [ ] Focus indicators remain visible throughout.
- [ ] Reduced-motion setting removes nonessential transitions.

Record browser/device, screenshots, issues and approval in `end-to-end-test-report.md`. Do not mark complete from responsive CSS inspection alone.
